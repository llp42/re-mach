# Rust implementation

Implement the kernel in Rust with `no_std`. Rust's types and ownership
model are the basis for internal interfaces and resource lifetimes; the
unsafe operations kernel development needs remain allowed under
[ADR 0008](0008-unsafe-policy.md).

- Use assembly embedded in Rust for operations that require it
  ([ADR 0009](0009-build-and-assembly.md)).
- Express ported logic in Rust, preserving its provenance
  ([ADR 0011](0011-licensing-and-provenance.md)).
- C exists only as the temporary DragonFly BSD base and its glue
  ([ADR 0015](0015-dragonfly-c-base.md)). New kernel logic is not written
  in C.
- Host-side development tools are outside this language constraint.
