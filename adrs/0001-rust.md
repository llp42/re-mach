# Rust implementation

Implement the kernel in Rust with `no_std`. Rust's types and ownership model
are the basis for internal interfaces and resource lifetimes. This commits
the project to a Rust implementation while allowing the unsafe operations
needed for kernel development.

Use assembly embedded in Rust for operations that require it. Ported logic
is expressed in Rust with its provenance preserved; C is not a parallel
kernel implementation language. Host-side development tools are outside
this language constraint.
