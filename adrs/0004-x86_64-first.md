# x86_64 first, architecture isolation

x86_64 is the first supported CPU architecture. Concentrating on one
architecture limits bring-up work, but shared kernel design must still
permit future architectures. A second architecture is not required now;
build interfaces around current requirements.

- Keep CPU instructions, register layouts, page-table formats, interrupt
  entry, and architecture-specific initialization behind an architecture
  interface, with CPU-specific code in `src/arch/<architecture>/`.
- Shared subsystems must not assume x86_64 register names, page sizes, or
  address layouts.
- Select the implementation at the architecture boundary, not with target
  checks spread through shared algorithms.
- Architecture support does not imply a particular boot protocol
  ([ADR 0005](0005-multiboot-first.md)).

The imported C keeps its upstream layout
([ADR 0015](0015-dragonfly-c-base.md)); Rust that replaces it follows
these rules.
