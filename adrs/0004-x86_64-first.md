# x86_64 first, architecture isolation

x86_64 is the first supported CPU architecture. Concentrating initial
development on one architecture limits bring-up work; shared kernel design
must still permit future architectures.

Keep CPU instructions, register layouts, page-table formats, interrupt
entry, and architecture-specific initialization behind an architecture
interface, with CPU-specific code in `src/arch/<architecture>/`.
Shared subsystems must not assume x86_64 register names, page
sizes, or address layouts. Select the implementation at the architecture
boundary instead of spreading target checks throughout shared algorithms.

Build interfaces around current requirements. A second architecture is not
required now, and architecture support does not imply a particular boot
protocol.
